# Dropbox Spaces Flex Gallery

A polished, responsive flexbox layout built with semantic HTML and CSS.

## Features

- Flexbox navigation with a left-aligned brand and right-aligned links
- Responsive card gallery using `flex-wrap`, `gap`, and `justify-content: center`
- Mobile layout that collapses cards into a single column
- CSS-built visual artwork with no image assets required
- Responsive typography, spacing, and accessible landmarks

## Run locally

Open `index.html` directly in a browser. No build step or dependencies are required.

## Project files

- `index.html` - page structure and gallery content
- `styles.css` - layout, responsive behavior, and visual styling
